## Absorption argument

The live corpus already allows Memory to be a context-dependent mapping and to include references, relations, functions, bindings, status, and derived views. Under that usage, a retriever is the access semantics of Memory, a context compiler is a Memory-to-current-state function, a learned procedure is procedural Memory, a relationship is relational Memory, and an environment binding may be current Memory/state. Much of “Memory is not enough” may therefore identify components of a sufficiently rich Memory system rather than independent substances.

This matters because the RED decomposition can otherwise double-count: `state × retrieval × compiler` may split one functional Memory relation into stored data plus operations that define its actual value.

## Limits of absorption

Absorption becomes vacuous if every causal input to behavior is renamed Memory. A base model's general linguistic competence, random seed, hardware error, provider safety policy, or unrecorded system prompt can alter behavior without plausibly being Persona-acquired Memory. The boundary should use principled membership conditions—such as Persona-specific acquisition, retention, addressability, causal availability, or governed self-relation—not explanatory convenience.

## Counterhypotheses

1. “Memory is not enough” is false only under a functional/system definition; it remains true for durable stored content.
2. Retrieval and compiler are constitutive **operations of remembering**, not Memory contents.
3. Learned reconstruction policy can be procedural Memory, while the generic execution engine is enabling infrastructure.
4. Relations may be jointly constituted and cannot be reduced to one Persona's internal Memory.
5. The debate may be about boundary placement rather than causal disagreement.

## Discrimination

Pre-register a Memory membership rule before interventions. Hold member-state fixed while varying excluded runtime components; then hold excluded components fixed while varying members. If proposed “external” mechanisms consistently explain continuity only by being retroactively reclassified as Memory, the broad hypothesis is unfalsifiable. If a stable membership rule predicts effects across swaps, the functional account gains content.

No source object is added. Five counterhypotheses are retained for the Codex-inference registry; neither narrow nor all-inclusive Memory is selected.
