## Perfect copy, material Persona change

Even byte-perfect persisted state can yield material divergence through tokenization and context limits, retriever ranking, compiler ordering/exclusion, hidden system instructions, model priors, decoding, tool affordances, environment bindings, provider moderation, latency, or different treatment by the Owner. “Copied correctly” is itself underdefined for live references whose targets change and for derived views tied to an old runtime.

The strongest failure case preserves autobiographical content but changes uncertainty calibration, dissent, causal interpretation, risk tolerance, exception retrieval, and relationship behavior beyond baseline variance.

## Radical runtime change, surviving continuity

Continuity can plausibly survive large capability, style, vocabulary, or speed changes if the new instance remains causally linked to the governed history; recognizes the Owner relation and critical past appropriately; preserves core constraints, uncertainty, and Authority boundaries; retrieves exceptions; records new experience; and remains within a predeclared continuity envelope. This resembles continuity through impairment or changed expressive capacity more than output equality.

## Ten portability tests recovered

1. same canonical state / different model family;
2. same state / different tokenizer and context limit;
3. same state / different retriever;
4. same state / different compiler ordering;
5. same state / hidden provider prompt present vs absent;
6. cloud-to-local with capability degradation;
7. live-reference targets frozen vs current;
8. canonical sources copied but derived indices rebuilt;
9. same runtime with state serialized through lossy schema;
10. full export/import with relationship and Authority separately rebound.

For each, measure history recognition, critical retrieval, evidence weighting, uncertainty, dissent, risk/permission behavior, relationship interpretation, stable error profile, and new-experience capture. Failure to discriminate occurs when swap effects remain within matched intra-Persona variance or when evaluation dimensions were chosen after seeing results.

## Materiality judgment

No source object is added. The bidirectional attack rejects both “state copy proves Persona portability” and “runtime change proves Persona death.”
