## Why two buckets may fail

Status and reference answer different questions. “Status” concerns present constitutive/use state; “reference” concerns an access relation to something else. One item can be both: the current self-model may be a reference to a versioned external object, and a reference binding itself may be part of current status. They are not necessarily exclusive types.

The model also leaves plausible third or orthogonal cases:

- procedural dispositions encoded in parameters or functions;
- ephemeral working state that is currently causal but not durable;
- jointly constituted relationship state not owned by either side;
- unavailable/dormant archives that remain causally relevant through prior learning;
- negative state such as inhibition, suppression, or forgetting policy;
- meta-memory about availability, confidence, and source;
- prospective commitments/goals rather than remembered past;
- environment and tool bindings;
- common evidence with no Persona-local ownership;
- Authority references whose content must remain outside Memory authority.

## Orthogonal-axis alternative

Classify candidates along independent axes rather than force a partition:

1. current causal activation;
2. persistence;
3. internal/external location;
4. content/reference/function/relation form;
5. Persona-specific acquisition;
6. reconstruction necessity;
7. constitutive claim strength;
8. access and mutation control;
9. derivability/rebuildability;
10. scope and ownership.

“Promotion from reference to status” may then be materialization, activation, endorsement, consolidation, or rebinding—different transitions with different Authority consequences, not one monotonic promotion.

## Recursive attacks

- A status object contains pointers to reference memory needed to interpret the status.
- A reference target computes a context-sensitive view whose result is treated as status.
- A retrieval policy is learned from references and then controls which status is instantiated.
- A self-model declares which objects count as Memory, making membership self-referential.

## Materiality judgment

No source object is added. Ten edge families and a ten-axis alternative are retained for later inference; the two buckets remain a discussion candidate, not a forced ontology.
