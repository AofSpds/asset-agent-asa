## Portability layers

1. source/state bytes;
2. schema and identifiers;
3. indices/derived views;
4. reconstruction interface and policy;
5. runtime/tool/environment bindings;
6. model-induced behavior within a baseline envelope;
7. learned expertise/procedure;
8. relationship continuity;
9. Authority bindings (separate and never implied by copy);
10. practical sovereignty and cognitive/relational exit.

Success at an earlier layer does not prove success at a later one.

## Bidirectional attack

### All persisted Memory copied correctly; Persona still changes

- model prior resolves conflicts differently;
- tokenizer/context budget shifts rare-memory activation;
- retriever/compiler differs;
- hidden system prompts/provider personalization remain;
- fine-tuned or adapter expertise is absent;
- function/environment bindings change;
- relational behavior changes beyond the Owner's continuity envelope.

### Model/runtime changes radically; continuity still survives

- core history and Owner relation are recognized;
- critical constraints and uncertainty behavior persist;
- relevant evidence is retrieved reliably;
- new experience is recorded safely;
- degraded capability is not mistaken for Persona death;
- Authority remains separately and conservatively bound;
- behavioral change remains within predeclared continuity-relevant variance.

## Relations recovered

1. Provider replaceability `DESIGN_INTENT_NOT_PROOF_OF` behavioral compatibility.
2. State portability `DOES_NOT_IMPLY` Persona portability.
3. Index rebuildability `DOES_NOT_IMPLY` retrieval equivalence.
4. Runtime portability `DEPENDS_ON` standardized reconstruction interface.
5. Expertise portability `DEPENDS_ON` representation.
6. Relationship continuity `REQUIRES_DEFINITION_AND_MEASUREMENT` beyond stored facts.
7. Local survivability `COEXISTS_WITH` capability degradation.
8. Technical exportability `DOES_NOT_IMPLY` practical exit.
9. Memory sovereignty `MAY_BE_NECESSARY_BUT_NOT_SUFFICIENT_FOR` Persona sovereignty.
10. State copy `DOES_NOT_IMPLY` Authority copy.

## Double-crux

Which deviations count as capability change and which as Persona change? Without a baseline envelope over continuity-relevant dimensions, both portability success and failure can be narrated post hoc.

## Materiality judgment

No new source object is counted. The pass creates a ten-layer portability frame and preserves both directions of the portability attack.
