## Five non-equivalent readings

1. **Metaphysical equality:** Identity literally is Memory. This is not the current intended claim; RED-I rejects it and the worldview disclaims a metaphysical truth claim.
2. **Constitutive sufficiency:** preserving all Memory is sufficient for the Persona. RED-I/II attack this with reconstruction, runtime, relation, lineage, and model contributions.
3. **Primary substrate:** Memory is the most important continuity carrier without being sufficient. This survived the source attack.
4. **Current-state construction:** a present state recognizes remembered history as its own and thereby instantiates identity-like continuity. This depends on an unexplained appropriation/recognition relation.
5. **Operational reconstruction criterion:** a restarted state uses relevant history well enough to count as continuous on chosen dimensions. This is measurable but may replace rather than answer the philosophical identity question.

These readings must not share one unqualified relation label. `SN-R1-CH-001 CONTRADICTS SN-MI-H-001` is accurate only for the literal reading; it `WEAKENS` or `CONSTRAINS` other readings.

## Strongest tensions

- Historical `MEMORY != CURRENT STATE` conflicts with a live model that instantiates Persona from `MEMORY_STATE_t`; it does not automatically conflict with Memory as history-bearing substrate.
- `Portable State != Portable Persona` refutes a narrow sufficiency claim, but a broad Memory definition could absorb retriever/compiler/runtime policy and evade the attack.
- Large memory loss with continuity and preserved memory with material Persona change form the cleanest paired counterexamples to sufficiency and necessity.
- Multi-dimensional continuity may operationalize evaluation while leaving the identity proposition undecided.
- The “own history” relation may require causal lineage, self-model, present commitment, Owner recognition, or merely a functional retrieval stance; the source does not choose.

## Relation corrections/candidates

1. RED-I literal rejection `CONTRADICTS_READING` metaphysical equality, not every Memory-centered hypothesis.
2. Memory-as-carrier `COEXISTS_WITH` multi-component identity.
3. Current-state construction `DEPENDS_ON` a remembered-history appropriation relation.
4. Process discontinuity `COEXISTS_WITH` causal lineage continuity.
5. Multi-dimensional evaluation `ALTERNATIVE_TO` a single operational boolean, not necessarily to philosophical identity.
6. Broad-Memory rescue `WEAKENS_FALSIFIABILITY_OF` Identity ?= Memory.

## Double-crux

If two states have identical accessible history but differ only in whether they recognize it as “mine,” does Persona identity differ? If yes, recognition/appropriation is independently constitutive; if no, the phrase “own history” is explanatory decoration. The current sources do not resolve this.
