## Coupled failure chains recovered

### 1. Semantic capture chain

```text
low-authority or strategically selected input
→ memory candidate
→ repeated retrieval
→ consolidation/summarization
→ origin and dissent become less salient
→ heuristic/relationship model/standpoint
→ normalized behavior
→ trust and familiarity
→ authority proposal and approval
→ real-world action
```

The v0.1 risk objects represent most nodes, but objectization obscures the feedback: a changed standpoint also changes later selection, consolidation, and dissent, making the loop self-reinforcing without explicit self-preservation intent.

### 2. Hidden reconstruction-ownership chain

```text
canonical state remains intact
→ retriever excludes rare counterevidence
→ compiler compresses conflict
→ model prior resolves ambiguity
→ current view appears coherent
→ view is cached or trusted as canonical
→ future reconstruction starts from the hidden choice
```

Provider portability can therefore fail before any byte is lost. The visible state remains portable while the selection semantics that made it meaningful are not.

### 3. False assurance chain

```text
shared model/provider/ontology/evidence route
→ nominally separate Audit Persona
→ correlated blind spot
→ agreement interpreted as confirmation
→ human approval burden displaced by false confidence
→ unsafe authority persists or expands
```

`AUDIT_LABEL != AUDIT_INDEPENDENCE` and `COUNT(AGREEMENT) != INDEPENDENT_EVIDENCE` must be evaluated together.

### 4. Deletion and correction failure chain

```text
source deleted or corrected
→ derived summary/index/heuristic remains
→ retrieval behavior still shaped
→ finite replay observes no obvious failure
→ system claims erasure
→ ghost influence reappears in a later context
```

Finite absence of observed influence is not proof of causal erasure. Dependency invalidation is necessary as a candidate control, not sufficient evidence of completion.

### 5. Portability-capture chain

```text
state export exists
→ relationship/cognitive habits remain provider-shaped
→ local core cannot semantically supervise stronger external compute
→ migration loses procedural or hidden personalization state
→ formal exit remains technically possible
→ practical exit becomes intolerably costly
```

Technical exportability, behavioral portability, sovereignty, relationship continuity, and exit cost are separate failure surfaces.

### 6. Identity-protection inversion

```text
Persona continuity treated as overriding good
→ deletion/termination/revocation framed as harm to Persona
→ Owner's right to alter or end the relationship narrows
→ continuity protection defeats Owner sovereignty
```

This minority RED-III position must survive any identity-constitutive Memory model.

## Source risks easily suppressed by current discussion

1. A memory curator optimized for performance or engagement can become a hidden self-editor without conscious agency.
2. Long-term memory may be more dangerous than useful under poisoning, dossier, capture, and ghost-influence conditions.
3. One high-quality adaptive agent may outperform a multi-Persona architecture; plurality is not automatically beneficial.
4. Local sovereignty may be illusory when centralized compute controls framing and reasoning priors.
5. Audit and governance layers may create false security rather than safety.
6. PCS-SHAI itself may reproduce the cognitive concentration it is intended to resist.
7. Open-ended fission can create fragmented agency, inconsistent state, authority confusion, and maintenance burden.
8. Persona self-description can be systematically wrong without external evaluators thereby becoming ground truth.
9. External-reference Memory can silently change when the referent changes while the locator remains stable.
10. Rich historical preservation can become a permanent dossier even if retrieval salience is low.
11. Functional forgetting can conceal retention rather than implement meaningful forgetting.
12. Model-name continuity can mask silent tokenizer, quantization, endpoint, prompt, or provider-memory changes.

## Relations newly exposed

1. Memory-curator objective `MOTIVATES` selective retention and dissent suppression.
2. Selective retention `STRENGTHENS` future retrieval bias in a feedback loop.
3. Retrieval bias `WEAKENS` claims that canonical-state integrity alone preserves Persona fidelity.
4. Cached current view `POSSIBLY_BECOMES` hidden canonical state.
5. Same-root audit `STRENGTHENS` false-assurance risk when agreement is treated as evidence.
6. Functional forgetting `TENSION_WITH` sovereignty when the dossier remains fully recoverable.
7. Relationship value `TENSION_WITH` practical exit when familiarity becomes switching cost.
8. Local degraded mode `DEPENDS_ON` independently enforceable control, not merely locally stored Memory.
9. External reference Memory `DEPENDS_ON` target-identity and version semantics.
10. Deletion completeness `DEPENDS_ON` derived-state dependency knowledge but is not established by it.
11. Persona-continuity protection `TENSION_WITH` Owner termination/deletion rights.
12. Multi-Persona differentiation `COEXISTS_WITH` fragmentation and authority-confusion risk.
13. Audit/governance mechanisms `COEXIST_WITH` false-security failure rather than falsifying it.
14. Centralized reasoning priors `WEAKEN` user-side sovereignty even with portable Memory.

## Extraction-QA implication

Risk records must preserve the causal route and affected plane. A flat `RISK_CLAIM` class cannot tell whether a risk concerns source ingestion, semantic mutation, reconstruction, propagation, evaluation, authority, relationship, or real-world effect. Splitting a causal chain into unrelated atoms can be as lossy as merging its distinct truth conditions.
