## REF-001 — AIDA controlled natural-language claims

```text
REFERENCE_ID = ASA-MI-REF-REP-001
NAME = AIDA
FULL_NAME = Atomic, Independent, Declarative, Absolute
REFERENCE_CLASS = RESEARCH_METHOD_PRIOR_ART
SOURCE_TYPE = PRIMARY_RESEARCH_PAPER
RELATION_TO_ASA_MI = SIMILAR_TO_ATOMIC_NATURAL_LANGUAGE_CLAIM_OBJECT
REFERENCE_WEIGHT = LOW_SUPPORTING_REFERENCE
ADOPTION_STATE = NOT_ADOPTED
```

Observed relevant idea:

```text
AIDA_SENTENCE_PROPERTIES = [ATOMIC, INDEPENDENT, DECLARATIVE, ABSOLUTE]
AIDA_SENTENCE -> NODE_IN_SCIENTIFIC_CLAIM_NETWORK
```

ASA-MI connection:

```text
AIDA_ATOMIC_CLAIM
~
ASA_MI_ATOMIC_STATEMENT_OBJECT
```

Important difference:

```text
AIDA != ASA_MI_REPRESENTATION_MODEL
```

ASA-MI additionally cares about hypothesis state, challenge relations, lineage, status evolution, Git history, and optional structured notation.

Source:

```text
TITLE = "Using the AIDA Language to Formally Organize Scientific Claims"
AUTHOR = Tobias Kuhn
YEAR = 2018
URL = https://arxiv.org/abs/1806.01507
```

```text
REFERENCE_ID = ASA-MI-REF-REP-002
NAME = Nanopublications
REFERENCE_CLASS = COMMUNITY_SPEC_PRIOR_ART
SOURCE_TYPE = NANOPUBLICATION_ASSOCIATION_GUIDELINES
RELATION_TO_ASA_MI = SIMILAR_TO_SMALL_SELF_CONTAINED_ASSERTION_WITH_PROVENANCE
REFERENCE_WEIGHT = LOW_SUPPORTING_REFERENCE
ADOPTION_STATE = NOT_ADOPTED
```

Relevant structure:

```text
NANOPUBLICATION = {
  ASSERTION,
  ASSERTION_PROVENANCE,
  PUBLICATION_INFO
}
```

Nanopublications explicitly support small structured assertions plus provenance and publication metadata, and may carry hypotheses, claims, negative results, or opinions.

ASA-MI connection:

```text
ATOMIC_CLAIM + PROVENANCE + PUBLICATION_METADATA
~
STATEMENT_OBJECT + EVIDENCE/ORIGIN + LINEAGE/METADATA
```

Important difference:

```text
NANOPUBLICATION != ASA_MI_HYPOTHESIS_LIFECYCLE
```

Current Nanopublication Guidelines are a community specification and explicitly state they have no official standards-organization standing.

Sources:

```text
URL_1 = https://nanopub.net/
URL_2 = https://nanopub.net/guidelines/working_draft/
SOURCE_STATUS = COMMUNITY_SPECIFICATION
```

# Reference-level interpretation rule

```text
FOR EACH EXTERNAL_REFERENCE R:
  R.STATUS = REFERENCE_ONLY
  R.NORMATIVE_EFFECT = NONE
  R.ADOPTION_EFFECT = NONE
  R.CAN_SUPPORT_DESIGN_DISCUSSION = TRUE
  R.CAN_OVERRIDE_OWNER_HYPOTHESIS = FALSE
  R.CAN_OVERRIDE_CURRENT_RESEARCH_STATE = FALSE
```

External references may:

```text
SUPPORT
REFINE
CHALLENGE
INSPIRE
PROVIDE_PRIOR_ART
```

They do not automatically:

```text
VALIDATE
AUTHORIZE
FREEZE
REQUIRE
REPLACE
```
