- approximately 36 models derived from / operating inside the current ASA-MI worldview, focused on enrichment, gap detection, formalization, integration, repair, or justified supersession;

The 36/12 split is a candidate cohort structure, not yet frozen.

## 1. Common baseline requirement

All models, regardless of worldview track, must pass basic substantive World Model qualification.

A philosophically rich position is insufficient if it cannot produce a serious World Model.

Common qualification should include:
- explicit world-semantic thesis,
- explicit primitive/derived/open commitments,
- explicit change semantics,
- native consequence,
- visible assumptions,
- falsification/revision/abandonment conditions,
- bounded operational or microprobe contact where appropriate,
- protection against tooling-only / ledger-only / encoded-answer pseudo-models.

`WORLDVIEW QUALITY != MODEL QUALIFICATION`.

## 2. Track A — Current-worldview enrichment

Track A researchers receive the full current ASA-MI worldview and reasoning lineage.

They should deeply understand it and then seek to:
- find theoretical poverty and missing dimensions,
- deepen or formalize thin concepts,
- split overloaded concepts,
- connect previously separated strong ideas,
- import useful prior art,
- improve implementation fit,
- preserve what is already strong,
- challenge or supersede non-P0 hypotheses when the gain justifies replacement cost.

The mission is enrichment, not mandatory opposition.

## 3. Track B — Purpose-aligned alternative worldviews

Track B is allowed to begin from materially different worldviews.

Its principal constraint is the project purpose rather than conformity to the current worldview.

The researcher should ask:

> Can my own worldview be embodied faithfully in a computational World Model that serves the intended human-compatible Persona substrate / vessel purpose at least as well as, or better than, the current ASA-MI worldview?

A central evaluation axis is `WORLDVIEW_TO_MODEL_FIDELITY`:
- Does the World Model actually realize the worldview it claims to represent?
- Are the worldview's distinctions, commitments, change semantics, and explanatory structure native to the model rather than merely described in prose?

Preferred anti-anchoring design:
1. give Track B the project purpose, basic qualification rules, and cohort-level constitutive constraints;
2. let each researcher independently form and freeze its worldview + World Model;
3. only after position freeze, reveal the detailed current ASA-MI worldview for comparative mapping and dialectic.

This avoids creating pseudo-alternatives that are merely negations of the current worldview.

## 4. Four distinct evaluation questions

Keep separate:

1. MODEL_BASIC_QUALITY — is it a serious World Model?
2. WORLDVIEW_TO_MODEL_FIDELITY — does it faithfully realize its own worldview?
3. PURPOSE_FIT — does the worldview/model combination serve the human-vessel / Persona INIT purpose well?
4. WORLDVIEW_CONTRIBUTION — does it enrich, expose gaps in, defend, challenge, coexist with, or supersede useful parts of the current ASA-MI worldview?

Do not collapse these into one scalar score.

## 5. Hybrid research architecture

Recommended combined structure:

### Whole-Model Competition
Integration pressure across the full worldview/model package.

### Modular Theory Challenge
Deep theory harvesting for specific domains such as identity/continuity, relation/constitution, change/ontogenesis, time/history, perspective/context, individuation/composition, human familiarity, and sovereignty.

### Problem-First Control
Use target phenomena / fixtures to induce theory without revealing the full current worldview first, to detect anchoring and missing dimensions.

### Evolutionary Successor Lab
After baseline model freeze, mutate selected models through failure-revision cycles to test evolvability, repairability, and whether theory or only implementation must change.

### Dual evidence structure
`ESSAY / DIALECTIC + MODEL SPEC / EVIDENCE`.

Open-ended theory explanation is preserved, but rhetoric is constrained by common computational/evidentiary surfaces.

## 6. Scientific intent

The desired outcome is not merely one winning World Model.

Primary outputs should include:
- STRONGER_WORLD_MODEL_SET,
- RICHER_THEORY_SET,
- WORLDVIEW_GAP_MAP,
- WORLDVIEW_DELTA_SET,
- PURPOSE_FIT_MAP,
- WORLDVIEW_TO_MODEL_FIDELITY evidence,
- SUCCESSOR / EVOLVABILITY evidence.

Track A primarily asks how to enrich the current worldview from within.
Track B asks whether a materially different worldview can satisfy the same purpose better.
Modular and Problem-First tracks test whether both are missing important theory.
Evolutionary successor research tests which structures improve under pressure.

This combination is currently the preferred research direction, subject to pilot evidence and Owner review.
