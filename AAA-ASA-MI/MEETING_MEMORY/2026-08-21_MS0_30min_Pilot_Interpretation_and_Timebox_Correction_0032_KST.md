## 3. Main limitation

The pilot did NOT provide:

Pilot representative labels remain quarantined and must not become Full MS0 priors.

## 4. Timebox correction

For future research pilots where the purpose includes observing sustained depth, elapsed time alone should not be the primary control.

Prefer mandatory evidence quotas and minimum depth contracts.

If a wall-clock pilot is specifically desired, use:

`TARGET_WALL_CLOCK = 30 minutes`
`EARLIEST_NORMAL_CLOSURE = T+25 minutes`
`OWNER_EARLY_CLOSE = allowed`
`FATAL_BLOCKER_EARLY_CLOSE = allowed with explicit reason`

Do NOT use a generic `ENOUGH_EVIDENCE -> stop` rule if the experiment is intended to measure what additional depth Codex can produce within the time budget.

## 5. Full MS0 implication

Do NOT automatically accept the pilot-generated `12–16 hours` estimate as authoritative.

That estimate was produced from a deliberately shallow seed pass and should itself be treated as a hypothesis.

Full MS0 planning should be driven by:
- required semantic depth per serious candidate,
- common toy-world evidence,
- executable/falsifiable probes,
- distinctness after common scenarios,
- diminishing-return behavior,
- Owner steering.

The pilot strongly supports keeping staged checkpoints and positive/negative independent filters.

## 6. Recommended next experiment

Before committing to a 12–16 hour Full MS0 run, a second bounded pilot may test DEPTH rather than BREADTH.

Possible design:
- 20–30 minutes,
- 2–3 structurally different candidates selected for process testing rather than ranking,
- one shared toy world,
- one shared query pack,
- at least one executable or formal micro-probe per candidate,
- mandatory minimum depth before normal closure.

This would estimate how expensive fair comparison actually is.
