## Core clarification
Owner explicitly rejects treating a mapping target as enduring or terminal.

Candidate interpretation:
- A target is a transient materialized state/cut in an ongoing mapping/process flow.
- What is target relative to one mapping may immediately become source for a subsequent mapping.
- Therefore source/target are relational roles in a transformation chain, not necessarily persistent object substances.

Minimal sketch:
X_t --f_t--> X_{t+1} --f_{t+1}--> X_{t+2} ...

Here X_{t+1} is target with respect to f_t and may immediately function as source with respect to f_{t+1}. The model should not infer persistence of X_{t+1} merely from its temporary target role.
