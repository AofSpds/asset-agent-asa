## 1. Owner-explicit priorities

OWNER_EXPLICIT:

- Diversity and flexibility are the first-priority qualities of the desired world model.
- The Owner does not expect one model to support every possible situation or protocol.
- A model should expose its own limits rather than pretending universal support.
- Knowing a model's failure boundary is itself valuable research output.
- If a genuinely necessary interaction/protocol cannot be supported within the current model, model variation / mutation is an intended research possibility.
- Such mutation is part of how the broader world/model ecology may be composed over time, not a post-hoc excuse to make a frozen candidate pass.
- The desired world is expected to be composed from heterogeneous models/representations and flexible interaction, not forced convergence to one universal form.

## 2. Current architecture implication

The target is not universal expressiveness.

A high-quality model may legitimately return:

- SUPPORTED;
- PARTIALLY_SUPPORTED;
- UNKNOWN;
- CONFLICT;
- OUT_OF_SCOPE;
- REQUIRES_SUCCESSOR_MUTATION.

## 3. Mutation discipline

Distinguish:

A. view/materialization change;
B. runtime state mutation due to modeled interaction/event;
C. semantic/model mutation.

For a frozen exact candidate, C requires a successor exact target with lineage. It must not be used as an in-place repair after test failure.

## 4. Evaluation implication

High-value evaluation dimensions include:

- diversity retention;
- protocol/interaction flexibility;
- support breadth without semantic distortion;
- explicit limit detection;
- honest failure-boundary reporting;
- mutation necessity detection;
- successor-mutation discipline;
- resistance to forced convergence;
- ability to coexist with other heterogeneous models.

Universal coverage is NOT required and should not be rewarded if achieved only through vacuous meta-framework claims.

## 5. Research consequence

Candidate generation should not optimize for a single omnipotent model.

It should allow:

- specialized models;
- complementary models;
- shared substrate + heterogeneous interaction semantics;
- model ecologies;
- successor mutation paths;
- NO ADEQUATE MODEL for some interaction classes.

The research objective is to discover useful model capability regions and their boundaries, not to hide those boundaries.
