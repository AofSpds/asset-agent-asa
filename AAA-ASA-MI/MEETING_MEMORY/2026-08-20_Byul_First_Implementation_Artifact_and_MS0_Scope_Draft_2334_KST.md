## 2. MS0 purpose draft

MS0 should take the accumulated worldview, hypotheses, counter-hypotheses, and unresolved alternatives and determine how a low-level world model named `한알` could be computationally modeled.

The milestone should:

1. reconstruct current research state without promoting undecided concepts into primitives;
2. compare multiple serious computational-model candidates;
3. identify which candidate structures preserve the current worldview with the least semantic distortion;
4. expose contradiction, missing semantics, accidental ontology lock-in, and implementation-driven distortion;
5. perform minimal executable spikes only where they help discriminate model candidates;
6. preserve decisions, failures, assumptions, alternatives, and OPEN questions in stage-level research meeting memory;
7. leave the project in a state where the first implementation artifact `별` can be designed rationally.

## 3. MS0 explicit non-goals draft

MS0 is NOT intended to:

- finalize the ontology of 한알;
- require Boundary, Instance, Event, Relation, or any other current candidate as a primitive;
- implement the final Persona;
- perform Persona INIT;
- implement ASA;
- prove AI liveness, consciousness, or moral status;
- convert current hypotheses into Requirements or Design Contracts;
- freeze a canonical World Model;
- rewrite historical Meeting Memory to match later interpretations;
- introduce new infrastructure merely because it is convenient;
- force a graph/database/OOP/event-sourcing architecture before comparison.

## 4. Working MS0 exit condition draft

MS0 does not succeed by finding a final truth.

A satisfactory exit is reached when the research has enough comparative and executable evidence to make a reasoned choice about what model direction should be used for the first implementation artifact `별`, while clearly preserving unresolved alternatives and MODEL_ASSUMPTIONs.

FAILURE / NON-CONVERGENCE is also a valid research result if the current worldview cannot yet be represented coherently without unacceptable semantic distortion.
