## 3. Core polynomial-functor idea, simplified

A polynomial can be read as an interface specification:
- positions = outputs / modes / things the system can present or do;
- directions at each position = inputs / responses the environment may provide at that position.

A dependent lens between polynomials gives a bidirectional interaction protocol:
- forward: one side's position influences the other side's position;
- backward: the receiving side's response/direction is translated back into a response/direction for the first side.

This makes interaction protocol first-class and compositional rather than treating it as an incidental property update.

## 4. Important distinction from Owner hypothesis

Classic polynomial interfaces still presume a current interface object/type. This is not fully objectless.

However, this can be interpreted as a local, provisional interaction boundary rather than a metaphysical primitive object.

The key research question is whether interface itself can be treated as a temporary materialized capability/interaction surface generated by prior interaction rather than a permanent identity-bearing essence.

## 5. Dynamic organizations

Dynamic Categories / Dynamic Operads model organizations whose interaction patterns can themselves evolve with state. The motivating idea is that natural organized systems adapt under internal/external pressure at multiple levels of abstraction.

This is stronger than fixed wiring:
STATE_t -> INTERACTION_PATTERN_t
INTERACTION -> STATE_(t+1)
STATE_(t+1) -> possibly different INTERACTION_PATTERN_(t+1)

But the participating systems' interface types were still fixed in this layer.

## 6. 2026 polynomial-tree extension

Spivak 2026 explicitly targets interactions that reshape the interfaces of the interacting parties.

A polynomial tree associates an interface polynomial to each node; after one round of interaction (output chosen + input received), the next child determines the next interface.

Simplified:
INTERFACE_t
+ OUTPUT_t
+ INPUT_t
-> INTERFACE_(t+1)

Thus present interaction changes the space of possible future interactions.

Examples in the preprint include:
- cells gaining or losing receptors in response to signals;
- sensors losing channels due to damaging inputs;
- neural systems increasing output resolution during training.

## 10. Most important newly exposed hypothesis

INTERACTION_GENERATED_INTERFACE_HYPOTHESIS:

The participant's current interface/capability boundary is not an intrinsic fixed property. It can be treated as a provisional result of prior interaction history and can itself be reshaped by interaction.

Candidate cycle:
INTERACTION HISTORY
-> CURRENT INTERFACE / CAPABILITY SURFACE
-> CURRENT POSSIBLE INTERACTIONS
-> ACTUAL INTERACTION
-> UPDATED INTERFACE / CAPABILITY SURFACE

This does NOT yet imply that interface is ontologically fundamental. It may still be a materialized view.
