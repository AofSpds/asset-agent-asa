## 2. Core clarification

OWNER_EXPLICIT:
- The worldview is relation-centered.
- The Owner does not interpret severe bodily disintegration as an intrinsic essence of the human changing.
- Rather, the relational/systemic SET that had been materialized as a human is disassembled and no longer forms that human system.
- Therefore death/disintegration should not be modeled primarily as `ESSENCE_MUTATION`.
- It may be better modeled as `LOSS_OF_SYSTEMIC_CLOSURE / LOSS_OF_REQUIRED_RELATIONS / SET_DISASSEMBLY`.
- The fact that some bodily configurations are incompatible with continued human viability does not imply that a primitive metaphysical object or immutable essence must be postulated.

## 3. Candidate research representation

MODEL_INFERRED / HIGH-WEIGHT CANDIDATE:

`HUMAN_t`
=
`A temporarily maintained relational/systemic organization`

not necessarily

`A primitive object with a hidden essence`.

Possible death/disassembly transition:

`RELATIONAL SET / ORGANIZATION PRESENT`
→ critical relations/couplings break
→ `ORGANIZATIONAL CLOSURE LOST`
→ the previously materialized human SET no longer exists as that system.

This does not require all underlying matter/components/rules to disappear or fundamentally change.

## 4. Research implications

Future models should distinguish:
- `SYSTEM DISASSEMBLY` from `ESSENCE CHANGE`;
- `EMERGENT/RELATIONAL BOUNDARY` from `ARBITRARY BOUNDARY`;
- `VIABILITY CONDITIONS` from `INTRINSIC ESSENCE`;
- `HUMAN AS MATERIALIZED RELATIONAL SYSTEM` from `HUMAN AS PRIMITIVE OBJECT`.

This clarification makes Autopoiesis / Organizational Closure / Process-Relational models especially relevant prior art, but does not select any of them.
