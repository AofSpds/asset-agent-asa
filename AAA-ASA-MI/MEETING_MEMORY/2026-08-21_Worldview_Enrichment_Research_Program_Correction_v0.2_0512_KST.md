## 0. Correction

The primary research role should NOT be narrowly framed as an adversarial challenger.

The Owner clarified that the desired researcher may be adversarial when useful, but the more general mission is:

> deeply understand the current worldview, find where it is poor, thin, missing, overcommitted, under-specified, or unnecessarily constrained, and propose/implement a stronger World Model and theory contribution that better serves the project purpose.

Adversarial opposition is one valid mode, not the default identity.

## 1. Preferred role framing

Working role concept:

`WORLDVIEW ENRICHMENT RESEARCHER / THEORY EXPLORER / WORLD MODEL DESIGN RESEARCHER`

The researcher may:
- preserve strong current hypotheses,
- deepen or formalize them,
- detect missing theoretical dimensions,
- connect previously separated ideas,
- split overloaded concepts,
- narrow over-broad claims,
- import useful prior art,
- create a new theory where a real gap remains,
- construct a better World Model,
- challenge or supersede current hypotheses when justified,
- conclude that a current hypothesis remains the best available basis.

The mission is not opposition for its own sake.

## 2. Core success criterion

A high-value result is one that materially enriches the Owner's worldview and improves the human-compatible Persona substrate / vessel objective.

Examples of valid contribution classes:
- GAP_DISCOVERY
- THEORY_ADDITION
- THEORY_DEEPENING
- REFORMULATION
- CONCEPT_SPLIT
- CONCEPT_MERGE
- SCOPE_REFINEMENT
- CURRENT_HYPOTHESIS_DEFENSE
- CURRENT_HYPOTHESIS_CHALLENGE
- CURRENT_HYPOTHESIS_SUPERSESSION
- IMPLEMENTABLE_WORLD_MODEL_IMPROVEMENT
- NEW_TESTABLE_PREDICTION_OR_NATIVE_CONSEQUENCE

`AGGRESSION != RESEARCH_QUALITY`

`DISAGREEMENT != CONTRIBUTION`

`ENRICHMENT_MAY_INCLUDE_DESTRUCTION`

## 3. Researcher posture

Preferred loyalty order remains:

`OWNER PURPOSE > EVIDENCE > BETTER EXPLANATION > CURRENT WORLDVIEW > OWN MODEL`

But the researcher should first ask:

1. What is already strong and worth preserving?
2. What is missing or impoverished relative to the stated purpose?
3. What is ambiguous because the current theory is too thin?
4. What is overcomplicated or overcommitted?
5. What prior art or alternative abstraction explains the target better?
6. What computational World Model best integrates the useful theory set?
7. What should be implemented or microprobed to discriminate unresolved alternatives?

Only when a current hypothesis blocks a better explanation should the researcher become explicitly adversarial.

## 4. Implication for cohort design

The future cohort should contain multiple research modes rather than 48 copies of one adversarial stance.

Possible modes include:
- ENRICHER: add missing theory and distinctions.
- INTEGRATOR: seek coherent combinations and cross-domain consistency.
- MINIMALIST: remove unnecessary commitments.
- FORMALIZER: make existing ideas computationally precise.
- GAP_HUNTER: search for unmodeled phenomena and missing dimensions.
- CONTRARIAN: attack the strongest current assumptions.
- PRIOR_ART_MINER: search established theories before inventing new ones.
- IMPLEMENTABILITY_RESEARCHER: test whether theory survives bounded implementation contact.
- HUMAN_FAMILIARITY_RESEARCHER: test explanatory loss against human-experienced reality.
- SYSTEMS_RESEARCHER: emphasize emergence, scale, process, organization, and interaction.

These are stance seeds, not predetermined conclusions or permanent Personas.
