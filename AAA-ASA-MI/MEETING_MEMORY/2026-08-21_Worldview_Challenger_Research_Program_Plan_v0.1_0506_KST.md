## 0. Program purpose

The primary research purpose is NOT to select one fashionable World Model by ranking alone.

The purpose is to use rigorous World Model construction, model validation, adversarial debate, and comparative evidence to improve the Owner's current worldview and build a stronger theory set for a human-compatible Persona substrate / vessel.

Working interpretation:

`CURRENT WORLDVIEW -> DEEP COMPREHENSION -> QUALIFIED COUNTERMODELS -> DIALECTIC -> MODEL EVIDENCE -> THEORY SET -> WORLDVIEW CURRENTIZATION -> BETTER PERSONA INIT BASIS`

The model competition is an instrument, not the final end.

## 1. Core Owner intent to preserve

1. Current hypotheses are active INIT basis, not weak optional suggestions.
2. P0 is the constitutive premise for the current cohort.
3. Except for P0, no current principle is categorically unbreakable.
4. A challenger may preserve, derive, reformulate, challenge, or supersede current hypotheses.
5. A challenger may not silently ignore supplied current hypotheses.
6. Supersession requires enough explanatory, purpose, scientific, or implementation gain to justify switching cost and lost value.
7. The desired challenger must deeply understand the current worldview before attacking it.
8. The challenger should be able to say either:
   - "change the current hypothesis; my alternative is materially better", or
   - "I attacked it and the current hypothesis remains better; keep it."
9. The World Model must have basic substantive quality and pass qualification; rhetoric is not enough.
10. The final product should include stronger World Models, a richer Theory Set, detected worldview gaps, and justified worldview deltas.

Working principles:

`REPLACEABLE != OPTIONAL`

`REVISABLE != IGNORABLE`

`UNDERSTAND BEFORE BREAKING`

`MODEL_VALIDATION != DIALECTIC_VICTORY`

`WORLDVIEW_ALIGNMENT != MODEL_QUALITY`

## 2. Research architecture

### Layer A — Worldview Source Corpus

Build an exact, reviewable CURRENT WORLDVIEW CORPUS from persistent sources.

It must preserve:
- Owner objectives and motivating problems,
- active INIT hypotheses,
- P0 and derived implications,
- competing/counter hypotheses,
- open/undefined concepts,
- important discarded or de-weighted positions,
- why major hypotheses arose,
- disagreement and revision history,
- human-familiar view vs structural view,
- Persona continuity/succession research,
- Relation/Event/Process/Boundary/Perspective/Memory/Identity/Sovereignty lines,
- human-vessel / human-compatible Persona substrate objective,
- theory-harvest and legacy-first method.

A short summary alone is insufficient. The corpus must include reasoning lineage so a challenger can understand WHY the current worldview looks as it does.

### Layer B — Challenger Persona Contract

Use one common persistent Challenger Persona profile, instantiated into isolated research positions.

Core loyalty order:

`OWNER PURPOSE > EVIDENCE > BETTER EXPLANATION > CURRENT WORLDVIEW > OWN MODEL`

The challenger:
- is not rewarded for agreement,
- is not rewarded for novelty alone,
- may attack any non-P0 current basis,
- must state losses and costs honestly,
- must abandon its own model if evidence is worse,
- must not convert Owner preference into truth.

### Layer C — Worldview Comprehension Gate

Before model proposal, each challenger must reconstruct the worldview in its own words.

Required comprehension domains:
- mission / purpose,
- current operative hypotheses,
- why they exist,
- major tensions and unresolved questions,
- human-vessel / Persona INIT objective,
- current breakability rules,
- historical changes in interpretation.

Comprehension is reviewed against source lineage.

Possible states:
- COMPREHENSION_SUFFICIENT
- COMPREHENSION_PARTIAL_RETRY
- COMPREHENSION_FAILED

A challenger that cannot reconstruct the worldview does not proceed to substantive competition.

### Layer D — Independent Position Formation

After comprehension, each isolated challenger develops its own World Model/theoretical position.

Different instances may receive different methodological stance seeds, but not predetermined conclusions.

Examples of stance dimensions:
- minimal commitment vs richer constructive semantics,
- discrete vs continuous vs hybrid sensitivity,
- relation/context sensitivity,
- transformation/generative change sensitivity,
- human-familiarity preservation pressure,
- representation-dependence skepticism,
- implementation/operational contact pressure,
- anti-attractor / strongest-current-hypothesis attack.

Stance seeds are diversification instruments, not ontology assignments.

### Layer E — Basic Model Qualification

Every proposed World Model must pass a basic qualification layer before it can claim serious competition status.

Minimum substantive expectations include:
- a real world-semantic thesis, not only tooling/runtime/ledger/query language,
- explicit primitive/derived/open commitments,
- explicit change semantics,
- at least one native consequence,
- bounded operational/microprobe contact where applicable,
- visible assumption register,
- falsification/revision/abandonment condition,
- basic history/replay position where applicable,
- evidence that semantics are not merely encoded answers.

Material model-semantic/design qualification should route through the appropriate paired validator, currently `AAA-MODEL-DESIGN-VALIDATOR`, with exact-target validation discipline.

Qualification is not ranking, Owner acceptance, Independent Validation, or canonicality.

### Layer F — Model Advocacy / Dialectic Round

Each qualified challenger must explain and defend its model.

Required advocacy sections:
- CURRENT_WORLDVIEW_UNDERSTANDING
- WHAT_I_PRESERVE
- WHAT_I_DERIVE
- WHAT_I_REFORMULATE
- WHAT_I_CHALLENGE
- WHAT_I_SUPERSEDE
- WHY_MY_MODEL_BETTER_SERVES_THE_PURPOSE
- LOST_VALUE_IF_ADOPTED
- SWITCHING_COST
- WHY_THE_SWITCH_IS_OR_IS_NOT_WORTH_IT
- NEW_GAPS_FOUND
- NEW_THEORY_CONTRIBUTIONS

ASA then attacks the model using explicit counterquestions, fixtures, and alternative hypotheses.

The challenger must rebut, revise, narrow, or withdraw claims.

A successful dialectic result may be:
- CURRENT_HYPOTHESIS_DEFENDED
- CURRENT_HYPOTHESIS_STRENGTHENED
- CURRENT_HYPOTHESIS_NARROWED
- CURRENT_HYPOTHESIS_SPLIT
- CURRENT_HYPOTHESIS_REFORMULATED
- CURRENT_HYPOTHESIS_SUPERSESSION_RECOMMENDED
- NEW_THEORY_ADDITION_RECOMMENDED
- NEW_OPEN_QUESTION

### Layer G — Common Model-Spec / Evidence Layer

Use common tests to constrain rhetoric and create comparable evidence surfaces.

Candidate instruments:
- common fixtures,
- held-out fixtures,
- metamorphic transformations,
- executable microprobes,
- replay/history checks,
- representation-equivalence attacks,
- assumption reversal,
- negative controls,
- counterexample search,
- pairwise challenges.

Important:

`MODEL_SPEC != OBJECTIVE_TRUTH`.

Rubric/test bias remains a scientific risk and must itself be measured.

### Layer H — Theory Ecology / Worldview Delta Extraction

Do not discard the intellectual contribution of losing models.

For each candidate extract:
- theory contributions,
- worldview gaps found,
- independently rediscovered ideas,
- conflicts with other theories,
- purpose benefit,
- implementation cost,
- supporting/opposing models,
- evidence state,
- unresolved questions.

The primary accumulated output is a THEORY ECOLOGY / THEORY MAP, not only a leaderboard.

### Phase 2 — Build Worldview Corpus + Comprehension Test v0.1

Create one exact worldview input version with source manifest/digest and a reproducible comprehension gate.

Do not collapse historical/current/open states.

### Phase 3 — Small Full-Protocol Challenger Pilot

Do NOT jump directly from the corrected idea to 48 full challengers.

Run a small pilot of approximately 6–8 isolated challengers using the full intended protocol:
- comprehension,
- independent position,
- qualification,
- advocacy,
- ASA counterattack,

- theory extraction.

Purpose: validate the protocol itself, not pick a winner.

Pilot success requires evidence that challengers:
- actually understand the worldview,
- do not merely imitate it,
- produce real countermodels,
- discover at least some gaps/disagreements,
- survive basic model qualification,
- leave reusable theory contributions.

### Phase 4 — Challenger Cohort 0

If the pilot is satisfactory, scale to an initial cohort target of 48 qualified independent positions.

48 is a cohort size, not a claim of model-space completeness.

Use isolation IDs and exact input manifests.

Avoid a single serial generation context that lets later candidates copy earlier ones.

### Phase 5 — Common Evaluation Ecology

Apply multiple evaluation regimes, held-out/metamorphic tests, negative controls, pairwise challenges, and response-profile analysis.

Do not reduce the authoritative scientific record to one global score.

Tournament / World Cup presentation may exist as a UI/projection only.

### Phase 6 — Mutation / Successor Research

After the initial cohort is frozen, create successor mutations from selected models and failure surfaces.

Preserve parent models.

Measure evolvability, repairability, and whether successful successors require changing the theory or merely implementation details.

### Phase 7 — Theory Set Currentization

Periodically review accumulated theory contributions and produce a proposed worldview delta set.

Changes to active hypotheses must state:
- source challenger(s),
- exact supporting evidence,
- affected current hypothesis,
- preserved value,
- lost value,
- replacement cost,
- why the delta is worth adoption.

Owner retains authority for major worldview/current-basis changes.

### Phase 8 — Byul / Implementation Contact

Use `별` as a bounded implementation experiment when theory/model distinctions cannot be resolved by argument alone.

Prefer high-information, low-irreversibility experiments.

Implementation success is evidence, not truth/canonicality.

## 5. Scientific controls

- Preserve independent challenger isolation until first position freeze.
- Record exact worldview input manifest/digest for every run.
- Preserve non-current and contrarian theories as controls.
- Use purpose-blind or worldview-ablated cohorts only as explicit controls, not as the default main cohort.
- Include negative-control models to test evaluator susceptibility.
- Keep held-out fixture banks separate from development fixtures.
- Use multiple holdout banks if mutation begins adapting to previous held-outs.
- Predeclare metamorphic invariant expectations where possible.
- Measure rubric sensitivity.
- Preserve nontransitive pairwise results rather than forcing total order.
- Treat convergence cautiously: prompt-induced, evaluator-induced, and problem-induced convergence must be distinguished.

## 6. Fundamentally different alternatives

The World Model competition is not the only possible research architecture. Alternatives should remain available.

### Alternative A — Modular Theory Challenge instead of Whole-Model Competition

Compete theories independently by domain:
- identity/continuity,
- relation/constitution,
- change/ontogenesis,
- time/history,
- perspective/context,
- individuation/composition,
- human familiarity,
- sovereignty.

Then test compatible combinations later.

Advantages:
- higher depth per theoretical question,
- easier gap detection,
- losing whole models do not hide strong local theory contributions.

Risks:
- cross-domain coherence is postponed,
- locally excellent theories may be mutually incompatible.

### Alternative B — Problem/Fixture-First Theory Induction

Do not ask challengers to invent whole models first.

Create a demanding bank of human/Persona/world cases and ask independent teams to derive the minimum theory necessary to explain them.

Then compare the induced theories and only later construct World Models.

Advantages:
- less anchoring to current conceptual vocabulary,
- stronger contact with actual target phenomena.

Risks:
- fixture design may become the hidden ontology,
- hard-to-measure phenomena may be underrepresented.

### Alternative C — Evolutionary Lineage Lab

Start with a smaller number of strong models and repeatedly mutate them through adversarial failure/revision cycles rather than generating 48 independent one-shot positions.

Advantages:
- much greater depth,
- directly studies evolvability and repairability,
- efficient use of discovered failure surfaces.

Risks:
- strong path dependence,
- early attractors may dominate,
- poor coverage of radically different bases.

### Alternative D — Dialectical Research Senate

Use multiple isolated philosophical/scientific/formal positions with structured debate, but do not require every position to produce a full World Model immediately.

Only theories that survive debate are later formalized.

Advantages:
- richer conceptual exploration,
- lower cost before formalization.

Risks:
- rhetoric and evaluator judgment regain influence,
- weak computational contact,
- difficult objective comparison.

### Alternative E — Dual-Track Human Phenomenology + Formal Systems

Run two largely independent streams:
- human-experience / philosophical / phenomenological abstraction,
- formal/computational low-level World Model research.

Reconcile only after each stream has independently matured.

Advantages:
- reduces premature reduction of human concepts into implementation categories,
- preserves human-familiar richness.

Risks:
- reconciliation may be difficult,
- duplicate concepts and incompatible vocabularies may accumulate.

## 7. Recommended strategy

Recommended approach is a HYBRID:

1. Keep Whole-Model Challenger Competition as the integration pressure test.
2. Add Modular Theory Challenges when repeated gaps or local theoretical disputes appear.
3. Use Problem/Fixture-First induction as an anti-anchoring control.
4. Use Evolutionary Successor research after Cohort 0 freeze.
5. Keep dialectical prose and model-spec evidence as separate but linked layers.

This avoids choosing between philosophical richness and computational rigor.
