membership / self-relation event; does not imply authority.

separate authority relation/event.

scope-local callability/materialization into Working Memory / active operational scope.

potentially too in-place-oriented as a technical verb. Material semantic evolution may instead create a successor materialization.

### FORK / CLONE

### RETIRE
active callability/materialization ends, historical lineage/provenance remains.

### RECOVER / SUCCESSOR
re-materialization / re-binding into a new successor instance rather than restoration of metaphysical identity.

Strong candidate:

`LIFECYCLE STATUS MACHINE`
should be compared against
`EVENT + RELATION + SUCCESSION MODEL`.
