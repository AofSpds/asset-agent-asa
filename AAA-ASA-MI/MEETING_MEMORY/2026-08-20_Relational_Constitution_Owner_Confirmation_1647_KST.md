## 3. Cheap Local Representation Is Allowed

OWNER_EXPLICIT:

If a tree structure is cheaper and sufficient for a particular network bundle, that bundle may be represented using a tree.

This is important because RELATIONAL CONSTITUTION does NOT imply that every implementation must be a maximally general graph/network representation.

Current interpretation:

`RELATIONAL CONSTITUTION != ONE UNIVERSAL RELATION DATA STRUCTURE`

A particular relational bundle may use:

- tree;
- set;
- graph;
- table;
- function;
- rule/constraint;
- event projection;
- or another representation,

if that representation is adequate for the bounded INIT implementation and its required semantics.

Implementation cost / suitability therefore remains a first-class selection criterion.
