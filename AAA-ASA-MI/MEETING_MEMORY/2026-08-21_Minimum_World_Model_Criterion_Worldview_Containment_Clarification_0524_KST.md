## 0. Owner correction

Owner clarified the intended minimum criterion for a World Model candidate:

> `모델의 최소 기준은 자신의 세계관을 그 안에 담을 수 있느냐.`

The minimum criterion must therefore NOT be overdefined as a fixed checklist derived from the current ASA-MI worldview.

Primary minimum question:

`CAN_THE_MODEL_FAITHFULLY_CONTAIN_AND_OPERATIONALIZE_ITS_OWN_WORLDVIEW?`

A candidate World Model is not required, at the minimum gate, to reproduce the Owner's current concepts or preferred ontology.

It must be able to embody its own claimed worldview sufficiently that the worldview is not merely external prose attached to an unrelated technical representation.

## 1. Implication

The following are evidence surfaces, not the definition of the minimum criterion itself:
- explicit semantic commitments,
- change/transition consequences where relevant to the worldview,
- native consequences,
- model queries,
- bounded probes,
- falsification/revision conditions,
- replay/history behavior where the worldview claims such structure.

These instruments help test whether the model actually contains its worldview.

They must not silently impose one ontology on every candidate.

## 2. Track A and Track B

### Track A — current-worldview enrichment
The model must first be capable of containing the worldview/theory position it actually proposes after deeply understanding the current ASA-MI worldview.

It may preserve, deepen, reformulate, challenge, or supersede current hypotheses.

### Track B — purpose-aligned alternative worldview
The model may be built from a materially different worldview.

The key question is whether:
1. the alternative worldview is coherent enough to state,
2. the model faithfully contains/operationalizes that worldview,
3. the combined worldview+model serves the human-compatible Persona substrate/vessel purpose well enough to be a serious alternative.

Therefore Track B must not be disqualified merely for lacking current ASA-MI vocabulary.

## 3. Evaluation separation

At least three questions must remain distinct:

1. `WORLDVIEW_TO_MODEL_FIDELITY`
   - does the model actually contain the worldview it claims?

2. `PURPOSE_FIT`
   - does that worldview+model combination serve the project purpose?

3. `COMPARATIVE_THEORY_VALUE`
   - does it preserve, enrich, challenge, or improve the current ASA-MI Theory Set?

Model qualification evidence may support these judgments, but should not collapse them into a single score.

## 4. Correction to prior wording

Earlier notes listed several substantive-model requirements as though they collectively defined basic qualification.

Corrected interpretation:
- those are candidate evidence tests for worldview containment and computational seriousness,
- not an immutable universal ontology checklist,
- the minimum scientific admission question is whether the model can faithfully carry its own worldview in a form that can be examined and pressured rather than remaining detached rhetoric.
