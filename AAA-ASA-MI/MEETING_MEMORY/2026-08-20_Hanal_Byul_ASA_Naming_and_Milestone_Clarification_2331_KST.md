## 1. Owner naming structure

CURRENT WORKING NAMES:

- `한알` = the low-level World Model name candidate.
- `별` = the first small milestone / first object-instance name candidate within the future implementation path.
- `ASA` = currently envisioned as the ultimate concrete instance/application target built through `한알`.

The Owner described the current directional narrative approximately as:

`한알` → World Model
`별` → first small instance/object milestone
`ASA` → ultimate instance target for the current project direction

This is a milestone/naming map only.

## 2. `별` naming context

`별` was selected partly because of the working MS0 codename `FIAT LUX — 빛이 있으라`.

The Owner states that `별` has additional intended meaning, but that meaning is not yet expanded here.

Therefore:

`별` MUST NOT yet be assigned formal semantics.

Do not infer that `별` is necessarily:
- Instance,
- Event,
- Relation,
- Object in an OOP sense,
- Persona,
- Boundary,
- atomic entity,
- conscious/living entity.

The current wording `first object / first instance / small milestone` is working language only and remains revisable.

## 3. `한알` handling

`한알` is currently treated as the World Model name candidate.

The Owner also clarified that `한알` was initially conceived with a Korean-language intuition roughly analogous to an `object`-like unit, but this is naming intuition, not a commitment to object ontology.

Earlier `AL`, shell/interior, and boundary imagery remain naming background only.

Boundary, Instance, Event, Relation and other possible primitives remain OPEN and may be discarded or restructured.

## 4. ASA position

Current Owner direction:

ASA is not the World Model itself.

ASA is currently imagined as an ultimate concrete instance/application implemented using the `한알` World Model.

A prior narrative metaphor compared ASA to an `Adam`-like first concrete inhabitant/instance of the modeled world. That metaphor remains poetic only and carries no theological or ontological authority.

## 7. Anti-overinterpretation rule

NAME != SEMANTICS
METAPHOR != ONTOLOGY
MILESTONE_LABEL != MODEL_PRIMITIVE

`FIAT LUX`, `별`, `Adam`, `한알`, `ONTOGENESIS` may guide human memory and project narrative, but MUST NOT be used to silently determine the formal architecture.

Formal meaning is assigned only when modeling/research justifies it.

## 8. Semantic adaptability of naming

Owner clarification:

The names were intentionally chosen because they can remain useful across multiple possible future model structures.

The model is not yet decided, and the names MUST NOT constrain that decision.

After the model becomes clearer, current semantic interpretation of the names may be refined, expanded, or remapped to fit the resulting model.

Therefore:

`NAME STABILITY` may coexist with `SEMANTIC INTERPRETATION EVOLUTION`.

This does NOT authorize rewriting historical records to imply that the later interpretation existed earlier.

Historical naming context remains preserved; later meaning is added as a successor/current interpretation.

In short:

NAME MAY PERSIST
+
CURRENT MEANING MAY EVOLVE
+
HISTORICAL MEANING MUST NOT BE RETROACTIVELY REWRITTEN.
