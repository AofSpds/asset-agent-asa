## 1. Open systems / decorated and structured cospans
Applied category theory models open systems as composable morphisms. Larger systems can be assembled from smaller systems by gluing along interfaces. This gives a formal language for hierarchical composition and interface-mediated interaction across electrical circuits, Markov processes, Petri nets, reaction networks, and dynamical systems.

Fit:
- Strong for composition and nested systems.
- Strong for treating connection/interface as first-class syntax.
- Weak if interfaces and systems remain fixed objects.

## 2. Wiring diagrams and open dynamical systems
Vagner, Spivak, and Lerman formalize open dynamical systems using wiring diagrams. A box at the syntactic level is only an interface; semantics can be supplied later by different algebras. Wiring diagrams can be nested hierarchically and support plug-and-play composition.

Key AAA harvest:
- `BOX / OBJECT REPRESENTATION` can be deliberately semantically empty at one layer.
- `INTERACTION / WIRING` and `SEMANTICS / DYNAMICS` can be separated.
- The same compositional syntax can host different semantic models.

Critical gap:
- Classical wiring pattern is often static.

## 3. Mode-dependent networks
Spivak and Tan (2015) study networks whose topology changes as the modes/states of modules change. Local systems can be abstracted as modules in larger networks while the interaction topology changes over time.

Key AAA harvest:
- Relation / interaction topology need not be fixed.
- Local state may determine changing connectivity.
- Hierarchical nesting survives time-varying interaction structure.

Gap:
- Components/modules and their interfaces are still comparatively pre-given.

## 4. Dynamic organizations / dynamic operads
Shapiro and Spivak (2022) introduce dynamic categorical structures for systems whose organizational patterns adapt to internal/external pressures at multiple abstraction levels. Their Org framework interprets morphisms as collective organizational patterns that change dynamically.

Key AAA harvest:
- The interaction/organization pattern itself can be stateful and adaptive.
- Composition rules can themselves be dynamic, not merely the states inside fixed components.
- This is substantially closer to `INTERACTION RULESET FLEXIBILITY` than classical static wiring diagrams.

## 5. Interaction reshapes participant interfaces — 2026 preprint
David Spivak, `Interactions that reshape the interfaces of the interacting parties` (arXiv:2602.17917, Feb 2026; PREPRINT / not treated as peer-reviewed fact).

The paper explicitly addresses a limitation of prior dynamic-organization work: interaction patterns could change while each party's interface stayed fixed. It introduces polynomial trees so each round of output/input can determine the participant's next interface. Examples include cells gaining/losing receptors, damaged sensors losing channels, and systems whose capabilities grow during training.

Strong AAA resonance:
`INTERACTION_t -> PARTICIPANT INTERFACE_(t+1)`
not merely
`INTERACTION_t -> PARTICIPANT STATE_(t+1)`.

This is materially closer to the Owner hypothesis that interaction can change what the interacting system *is able to be / do / connect to*, and therefore can change the effective boundary or system definition.

## 8. Critical caution
This family still generally represents systems/parties/interfaces as mathematical objects. It does NOT establish the stronger claim that no primitive objects are needed. It may instead offer a rigorous intermediate architecture in which objects are deliberately thin interfaces while interaction, dynamics, and interface change carry most of the semantics.
