- The research target is `WORLD MODEL = OBJECT MODEL + PROTOCOL MODEL + BIDIRECTIONAL INTERACTION`.

- `VIEW_MATERIALIZATION`, `RUNTIME_STATE_MUTATION`, and `MODEL_SEMANTIC_MUTATION` are distinct operations.
